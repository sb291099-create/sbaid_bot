# Документы клуба

Положите сюда PDF-файлы с такими именами:

| Файл | Документ |
|---|---|
| `oferta.pdf` | Оферта |
| `ustav.pdf` | Устав клуба |
| `pravila.pdf` | Правила торгов |
| `politika-pd.pdf` | Политика обработки персональных данных |

Бот отправляет каждый найденный файл любому человеку перед кнопкой «Мне есть 18 лет,
принимаю оферту и правила» и по команде `/rules`. Вместо файла или вместе с ним можно
указать ссылку в `.env`: `OFFER_URL`, `CHARTER_URL`, `RULES_URL`, `PRIVACY_URL`.

Новые файлы подхватываются сразу, перезапускать бота не нужно. Поменяли оферту —
поднимите `OFFER_VERSION` в `.env` и выполните `docker compose up -d`.
